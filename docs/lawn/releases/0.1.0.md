# Lawn 0.1.0

Lawn is a terminal workspace for focused local development, based on herdr.
This release targets macOS Apple Silicon.

Lawn uses its own command and local settings. The inherited `HERDR_*` socket
and hook variables remain compatible with herdr's runtime.

The workspace sidebar fills the available space, with Jump directly in its
header. Machine and workspace rows have no aggregate agent attention badges.

Park any workspace pane in Later without stopping its terminal. Later folds
by machine and workspace. Its previews are read-only until explicitly restored,
and the parked list survives reconnects and is shared by Lawn windows locally.
Parking the final visible pane keeps its workspace open with access to Later.

Jump and tab indicators summarize active panes. Agent rows retain herdr's
status colors and circles; ordinary terminals have no agent indicator. Tabs
show the highest-priority visible state (blocked, working, then idle), with a
count when more than one agent is blocked.

Park, Restore, and Open Later shortcuts are configurable and unbound by default.
Parking requires Lawn's optional per-client runtime extension; it does not
change another client's layout or the session's shared pane topology.
